# Challenges

Worked solutions to SQL, Python, R, and Java interview problems from three practice platforms: DataLemur, HackerRank, and StrataScratch.

Each file is a single problem write-up: the original challenge statement, a link back to the source problem, the accepted answer, a screenshot of the result on the platform, and a step-by-step explanation. Many files also include an alternative-solution discussion (for example a window-function variant versus a self-join, or `Counter` versus a manual dictionary).

This is a study and reference repository. There is no application to run, no build step, and no test harness. Every solution lives inside its own Markdown file and is meant to be read on GitHub.

## How to use

1. Open any file below. The first line links to the original problem on the source platform.
2. Read the challenge statement, then try it yourself before scrolling down.
3. Compare against the accepted answer and the explanation. Where a file lists an alternative solution, the trade-offs between the two are spelled out.

The SQL targets standard PostgreSQL and MySQL dialects as used by each platform. Run the queries in the platform's own editor (or any matching database) to reproduce the screenshots.
